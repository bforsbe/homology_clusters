# Notes for Claude Code

Start with `docs/handoff.md` (aims, priorities, traps, conventions), then `docs/strategy_1.md` and `README.md`.

Short version: this repository builds a systematic, curated collection of fungal PDC E2 / OGDC-BCKDC E2 / E3BP (protein X) sequences, with the widest possible search, so that general motifs (notably the component-binding domain, which no database annotates) can be derived to define and trace function and to predict complexes. Annotation (UniProtKB, UniParc) is only the first net; sequence search from curated profiles is the second. Keep every inclusion traceable, document every notebook step in its markdown cell, print progress in long steps, and do not claim live-API behaviour that has only been tested on a mock.
